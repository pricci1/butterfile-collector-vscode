# Butterfile Collector for VSCode

Create and manage file groups (collections) within your workspace. Perform actions on all files in a collection.

## Features

- **Create and Name Collections:** Group files under meaningful names (e.g., "Authentication Feature", "Database Migrations").
- **Add Files Effortlessly:** Add files to collections directly from the VSCode Explorer or using commands.
- **Manage Collections in a Dedicated View:** A dedicated sidebar view provides a clear overview of all your collections and their included files.
- **Powerful Actions:** Perform common tasks on entire collections with a single click:
  - **Open All Files:** Open all files in a collection in your editor, instantly setting up your working environment.
  - **Copy File Paths:** Copy relative or absolute file paths to the clipboard, perfect for sharing or scripting.
  - **Clone Collections:** Quickly duplicate existing collections to create variations or new contexts.
  - **Rename and Delete Collections:** Keep your collections organized and up-to-date.
- **Workspace-Scoped:** Collections are stored in your workspace, ensuring they travel with your project.
- **Import and Export Collections:** Easily share your collections with others or transfer them between projects.

## Usage

1.  **Create a New Collection:** Use the command palette (`Ctrl+Shift+P` or `Cmd+Shift+P`) and search for "File Collections: New". Enter a name for your collection.
2.  **Add Files to a Collection:**
    - Right-click on a file in the Explorer and select "Add to Collection".
    - Use the command palette (`Ctrl+Shift+P` or `Cmd+Shift+P`) and search for "File Collections: Add file to collection".
3.  **Manage Collections:** View and manage your collections in the "File Collections" sidebar.
4.  **Perform Actions:** Right-click on a collection or a file within a collection in the sidebar to access available actions.
